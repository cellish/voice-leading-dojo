# 段階3b で変わる VL の判定(作者の確認用)

`node test/baseline/changes.mjs` で作った一覧。記録 `test/baseline/examples.json`(既定の設定)と、段階3b の修正後の `check()` の結果の差。
**この一覧を作者が確かめてから**、`node test/baseline/generate.mjs` で記録を作り直す(QUEUE T18)。

## 何を変えたか

- **core 0.5.0(T17、D27(a)(b))**: 同度のまま並行すると「連続8度」と出ていたのを「連続1度（同度）」に。外声(ソプラノ–バス)が同じ向きに進み、ソプラノが跳躍して完全協和へ入るとき、前が別の種類の完全協和(5度→8度、8度→5度)でも `hidden`(並達)に
- **augMel(D14、VL の規則)**: S・A・T の、増2度・増4度・増5度(複音程は単音程に直す)と、直後に反対方向へ2度進まない減5度。同じ音名の半音の動き(増1度)は当てない。減5度の次の音が未入力なら保留、最後の和音へ減5度で入ったら当てる。今までは S・A・T の増2度・増4度(単音程)だけ
- **バス**(与えられた声部)は判定に出さない。課題を読み込むときに「バスの第n→n+1音が増2度です。実施では直せないので、判定には出しません。」と知らせる(例題6つのバスには当たるものが無い)

## 確かめてほしい点

1. **外声の8度→5度も並達5度になる**: D27(b) は「5度→8度」だけを挙げていたが、教本の通常の定義(同じ向きの動きで完全協和へ入り、前が同じ種類の完全協和でないもの。GR と同じ)に合わせたので、8度→5度も当たる(下の `ex2/shift-33`・`ex3/shift-33`・`ex4/shift-44` の「並達5度」)。5度→8度だけにするなら、コアにパラメータを足す
2. **複音程の名前**: 増音程は単音程に直して当てる(作者の決定)ので、オクターヴを超える跳躍は「増11度」「増18度」(=2オクターヴ+増4度)のような名前で出る。オクターヴを超える跳躍には `leap` も出る
3. **減5度の文言**: 「…が減5度で進み、次に反対方向へ2度進んでいません」、最後の和音へ入るときは「…が減5度で最後の和音へ進んでいます（減5度の後は反対方向へ2度進んで解決します）」。次の音が未入力の間は出さない
4. **増2度・増4度の文言は今までと同じ**(「…が増2度で進んでいます」)。今まで出ていた `augMel` で、消えたり変わったりしたものは無い
